## Anti-Patterns Verdict — the five scrutiny areas

**LLM assessment: LOW slop.** Disciplined, intentional interface. Remaining findings are drift-from-spec, not template sludge.

### 1. Font intentionality — real fonts, two spec drifts
- Archivo variable + 3 Plex Mono weights genuinely self-hosted and valid on disk (lines 16–19); sane fallback stacks (51–52). Not default.
- **Drift 1:** `.prompt-input` (583) is mono; DESIGN.md commits "the prompt composer is Archivo." Fix: `font-family: var(--font-ui)` (keep engineer textarea mono) — or amend DESIGN.md; pick one.
- **Drift 2:** `.step-name` (876) is mono; DESIGN.md specifies Archivo step names + mono step-msg. The build log speaks 100% machine voice, flattening the two-voice contrast. Fix: `font-family: var(--font-ui); font-size: 16px; font-weight: 600;`
- **Adjacent:** the Borrowed-Accent Rule is already broken — mesh renders `0x3fcf85` (2942, 2994), not jade `#45d38a`. Fix: `color: 0x45d38a` in both materials.

### 2. Templated copy — clean, three soft spots
No "[Verb] the [Noun] with [Buzzword]", no Unlock/Empower/Transform. Hero is non-transplantable. But:
- 1706: `Saving to cloud` → `Saving to your library`
- 1905: `Kite AI — agent auth` → `Kite AI — connecting agents`
- 1837: `Create your first model` (the one SaaS-onboarding phrase) → `Describe your first object`
- 1855: adjective-stacked Engineer blurb → `It researches real dimensions, writes the CAD, and checks the part for strength.`

### 3. Cookie-cutter grids — the claimed asymmetry is REAL
- Mode panels verified: `1.45fr 1fr` (361), jade-edged Make panel vs plain graphite Engineer (387–397). "Lit door / graphite door" holds in code.
- Library grid (1226) is uniform but thumbnails are the problem: `◼`/`◻` glyphs (2509) make it read as identical gray rectangles, and the glyph meaning is never explained. Fix: canvas snapshot at save time, or ⬡ motif + prompt-derived label.

### 4. Stock icons — mostly earned, one filler
All SVGs `aria-hidden` beside text labels (3095). Hexagon motif system (logo → step icons → aside bullets → toast) is the strongest icon work. **Filler: Engineer badge (1848–1851) is the stock feather gear/sun** — says nothing about measurement. Fix: dimension-line glyph, e.g. `<path d="M3 9h18M3 15h18M6 9v6M18 9v6"/>`.

### 5. Other AI tells
- Gradient text: 0. Glassmorphism: 0. Kickers: all name real modes/machine fields — One-Kicker Rule holds.
- **Arrow CTAs (banned):** `Start →` (1578), `Open →` (1587). Fix: drop the affix; keycap edge + jade carry affordance.

## Overall Impression
The system survived scrutiny it was designed to invite. What's left is the gap between the committed DESIGN.md and the shipped code — the two-voice drift, the broken accent lock, the undocumented glow — plus one real UX hole: an un-cancelable multi-minute pipeline on a shared walk-up kiosk.

## What's Working
1. **The build log is a real signature component** — real toolchain names, `aria-live`, ⬡ motif, progressive spec/SCAD/analysis panels. "Progress you can trust" is implemented, not aspirational.
2. **Push-to-talk engineering** (2052–2196): interim-transcript folding, debounced restart around Chrome's 60s teardown, document-level safety nets so the mic never sticks.
3. **`retryLastBuild`** (2424–2441): a failed build returns the user to their own words.
